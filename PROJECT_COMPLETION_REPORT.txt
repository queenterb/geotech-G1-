KEY COMPONENTS EXPLAINED
════════════════════════════════════════════════════════════════════════════════

MAIN DETECTOR (cis/main_detector.py)
  • Listens on Unix socket for eBPF events (JSON JSONL format)
  • Validates each event against strict schema
  • Fuses software + side-channel data
  • Feeds features into LSTM-GNN for prediction
  • Runs immune memory detection (majority vote)
  • Triggers counterfactual simulation on suspicion
  • Intervenes if counterfactual shows prevention
  • Writes alerts and status updates
  • 100ms decision cycle

IMMUNE MEMORY (cis/immune_memory.py)
  • 256 antibodies (neural detectors) in pool
  • Majority-vote detection (top-10 vote)
  • Clonal selection: high-affinity antibodies produce more clones
  • Mutation: slight weight perturbation for diversity
  • Offline training with labeled data
  • Online adaptation after real detections

INTERVENTION ENGINE (cis/intervention_engine.py)
  • SIGSTOP process (freezes it immediately)
  • Optional cgroup CPU limits (starves process)
  • Optional ZFS snapshot + rollback
  • Logs full causal trace for investigation

SIDE-CHANNEL DAEMON (cis/side_channel_daemon.py)
  • Power: Intel RAPL (pkg, cores, DRAM)
  • Acoustic: Microphone if available, else disk I/O heuristic
  • Thermal: CPU coretemp
  • 100ms sampling window
  • Graceful fallback if hardware unavailable
