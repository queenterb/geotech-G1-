OPTION 1: INSTANT PROTOTYPE (ANY OS)
──────────────────────────────────────────────────────────────────────────────────

Windows:
  1. Navigate to project folder
  2. Double-click:  quickstart.bat
  3. Open another terminal, cd to cis/, run:
     python simulate_events.py
  4. Check alerts:
     type \tmp\cis_alerts.jsonl

Linux / macOS:
  1. Navigate to project folder
  2. Run:  bash quickstart.sh
  3. Open another terminal, cd to cis/, run:
     .venv/bin/python simulate_events.py
  4. Check alerts:
     tail -f /tmp/cis_alerts.jsonl


OPTION 2: LINUX HOST DEPLOYMENT (Production)
──────────────────────────────────────────────────────────────────────────────────

Step 1: Install (5 minutes)
  sudo bash deploy/scripts/install_cis.sh

Step 2: Build eBPF (2 minutes)
  cd ebpf && make
  sudo install -m 0555 detector_loader /usr/local/bin/

Step 3: Start Services (1 minute)
  sudo systemctl daemon-reload
  sudo systemctl start cis-ebpf-loader cis-sidechannel cis-digital-twin cis-main
  sudo systemctl enable cis-{ebpf-loader,sidechannel,digital-twin,main}.service

Step 4: Verify (1 minute)
  sudo systemctl status cis-main
  sudo /usr/local/bin/cis-health
  cat /tmp/cis_status.json | jq .

Step 5: Run Smoke Test
  sudo bash deploy/scripts/smoke_test.sh


OPTION 3: CONTAINER DEPLOYMENT
──────────────────────────────────────────────────────────────────────────────────

Using Docker:

WHAT TO EXPECT
──────────────────────────────────────────────────────────────────────────────────

When running simulate_events.py with high write-ratio (default 0.98):
  ✓ 500+ synthetic "file writes" injected
  ✓ Within 1-2 seconds: divergence detected
  ✓ Process marked suspicious
  ✓ Alert written to /tmp/cis_alerts.jsonl
  ✓ Status updated showing high encryption_indicator

Alert format (JSON):
  {
    "event": "counterfactual_trigger",
    "pid": 9999,                           ← suspect process ID
    "divergence": 0.42,                    ← prediction vs actual
    "future_encryption": 0.15,             ← if we killed it
    "current_encryption": 0.89,            ← before intervention
    "immune_alarm": true,                  ← immune detection fired
    "heuristic_alarm": true,               ← high write rate
    "intervention": {
      "isolated": true,                    ← SIGSTOP sent
      "snapshot": "cis_pre_1710000000",   ← optional rollback point
      "rolled_back": false                 ← rollback performed?
    },
    "timestamp": 1710000000.123
  }


TROUBLESHOOTING
──────────────────────────────────────────────────────────────────────────────────

"No alerts generated":
  1. Check socket exists: ls -la /tmp/cis_ebpf_events.sock
  2. Check decoder status: cat /tmp/cis_status.json
  3. Run synthetic: python simulate_events.py --count 100
  4. Check thresholds: grep -i threshold cis/config.example.json

"Service won't start (Linux)":
  1. Check logs: sudo journalctl -u cis-main -n 50
  2. Model exists: ls -la cis/models/lstm_gnn_scripted.pt
  3. Permissions: ls -la /tmp/cis*

"Tests failing":
  1. numpy installed: python -c "import numpy"
  2. psutil installed: python -c "import psutil"
  3. Run from cis/ directory
